# CAD and Graphics Projects

A collection of C++ projects focused on computer-aided design, computer graphics, databases and Windows desktop applications.

## Projects

### MySQL

An MFC desktop application demonstrating interaction with a MySQL database.

The project includes functionality for working with database records, filtering and displaying data through a graphical interface.

### OpenGl

A desktop application demonstrating computer graphics using OpenGL.

### SDIProjectCourse

A course project based on the MFC Single Document Interface (SDI) architecture.

The project contains graphical components and CAD-oriented functionality.

### Sdi_test

An MFC SDI application containing experiments with graphical interfaces, colors, lines and tree views.
